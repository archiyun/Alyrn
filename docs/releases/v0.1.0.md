# CoroPact 0.1.0

## Overview

CoroPact 0.1.0 is the first installable release of a C++23 coroutine-based
asynchronous networking runtime for Linux.

It provides a unified asynchronous I/O contract over two independent backends:

- Reactor backend based on epoll
- Optional io_uring backend based on liburing
- Coroutine `Task`, `AsyncStream`, listener, connector, timer, and source APIs
- CMake package exports through `find_package(CoroPact)`
- Debian, tarball, and Arch `PKGBUILD` installation paths

## Highlights

- Owner-thread Reactor event-loop and stream operations
- io_uring worker/ring topology with multishot and mailbox support
- Shared backend-neutral networking contracts
- Relocatable CMake targets such as `CoroPact::coropact_reactor` and
  `CoroPact::coropact_luring`
- Docker-based release artifact generation

## Installation

### Any Linux distribution

The portable installation path builds the release source archive with CMake:

```bash
VERSION=0.1.0
curl -fL \
  "https://github.com/archiyun/CoroPact/archive/refs/tags/v${VERSION}.tar.gz" \
  -o "CoroPact-${VERSION}.tar.gz"
tar -xzf "CoroPact-${VERSION}.tar.gz"

cmake -S "CoroPact-${VERSION}" -B build-coropact -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_TESTS=OFF \
  -DBUILD_EXAMPLES=OFF \
  -DCOROPACT_ENABLE_URING=ON \
  -DCMAKE_INSTALL_PREFIX=/usr/local
cmake --build build-coropact
sudo cmake --install build-coropact
```

Install liburing >= 2.6 development files before enabling the io_uring backend. For
a Reactor-only installation, use `-DCOROPACT_ENABLE_URING=OFF`.

### Debian and Ubuntu

Download and install the `.deb` asset:

```bash
gh release download v0.1.0 \
  --repo archiyun/CoroPact \
  --pattern '*.deb'
sudo apt install ./*.deb
```

The io_uring-enabled package requires `liburing-dev >= 2.6`. If the
distribution package is older (Ubuntu 24.04 ships an older development
package), build liburing 2.9 or newer using the instructions in
[`docs/packaging.md`](../packaging.md), or choose the Reactor-only build.

### Arch Linux

Build and install the native package with `makepkg`:

```bash
git clone --depth=1 --branch v0.1.0 \
  https://github.com/archiyun/CoroPact.git
cd CoroPact/packaging/arch
makepkg -si
```

### Tarball layout

The prebuilt tarball is a `/usr`-relative system-layout artifact:

```bash
gh release download v0.1.0 \
  --repo archiyun/CoroPact \
  --pattern '*.tar.gz'
sudo tar -xzf coropact-*.tar.gz -C /
```

Use the CMake source installation or a native package when package-manager
tracking and clean removal are required.

## Usage

```cmake
find_package(CoroPact CONFIG REQUIRED)

add_executable(my_app main.cc)
target_link_libraries(my_app PRIVATE CoroPact::coropact_reactor)
```

For io_uring:

```cmake
find_package(CoroPact CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE CoroPact::coropact_luring)
```

## Requirements

- Linux
- CMake 3.20 or newer
- A C++23-capable compiler
- liburing >= 2.6 development files for the io_uring backend
- A kernel with the capabilities required by the selected io_uring path

## Status

This is an experimental first release. The public API and binary packaging
layout may change before 1.0.0. The project is currently Linux-focused and
does not promise stable ABI compatibility across minor releases.
